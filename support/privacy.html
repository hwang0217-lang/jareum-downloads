회원가입과 소셜 로그인

회원가입은 보호자의 Google·카카오 계정으로 진행해요. 이메일·비밀번호를 직접 입력하는 가입은 제공하지 않아요. 선택한 서비스에서 동의한 계정 식별자와 기본 프로필 정보(제공되는 경우 이름·이메일·프로필 사진)를 회원 식별과 로그인 유지에 사용해요. 인증 정보는 자람 전용 Supabase Auth에서 처리하고, 아이의 생일·키·체중 기록은 업로드하지 않아요. Android의 로그인 유지 정보는 기기의 보안 키로 암호화해 저장해요. 웹은 해당 탭의 세션 저장소를 사용해요.

회원 계정 삭제는 내 계정 → 회원 탈퇴에서 요청할 수 있어요. 소셜 계정 자체가 삭제되지는 않으며 유료 구독은 Google Play에서 별도로 해지해야 해요. 회원 탈퇴 시 이 기기에 연결된 성장 기록도 삭제해요. 직접 저장한 백업 파일과 다른 기기의 파일은 직접 관리해 주세요.
